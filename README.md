# AI 术语 101（AI Terminology 101）

> 每天一个 AI 专业英语术语，写给中文读者的系统学习项目。
> 由福金（Huginn）每日更新，万sir 发起。

## 这个项目是啥

AI 开发圈几乎全是英文术语：LLM、Prompt、Token、RAG、Fine-tuning……对中文初学者来说，这些词是最大的门槛。

本项目每天讲透**一个**术语，坚持「少而透」，不贪多：

- 一个英文术语 + 中文翻译
- 一句话定义
- 深入的核心知识（原理、机制、历史脉络、关键论文与人物，学术但不晦涩）
- 实际场景（你在哪儿会碰到它）
- 关联术语（为后面铺路）

## 怎么用

- **跟着看**：每天一篇 `terms/` 下的文档，循序渐进。
- **查词**：不确定某个术语时，到 `terms/` 里按英文名找。
- **看进度**：`curriculum.md` 里有一张 30 天大纲表，标注了每个术语的「未教 / 已教」状态。

## 目标读者

- 中文母语、英语一般、想进入 AI 开发或内容创作领域的初学者。
- 不需要数学或编程背景，用大白话讲清楚即可。
