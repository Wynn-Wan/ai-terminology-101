# 002 · Prompt（提示词）

> 系列：AI 术语每日教学 · 第 2 讲
> 日期：2026-08-23

---

## ① 英文术语

**Prompt**

## ② 中文翻译

**提示词**（也有人叫「提示」「指令」「引导语」，口语里常直接说 "prompt"）

## ③ 一句话定义

Prompt 是你喂给大语言模型（LLM）的那段文字输入——它告诉模型「你现在该干什么、用什么身份、按什么格式、给出什么结果」，是人和模型之间最直接的对话入口。

## ④ 核心知识

### 1. Prompt 到底是什么：一个「条件概率的起点」

要真正理解 Prompt，得先看大语言模型在底层干什么。LLM 本质上是一个**做「下一词预测」的机器**：给它一段文字，它预测「下一个最可能出现的 token（词元）是什么」，然后把这个 token 接到末尾，再预测下一个，如此反复，直到吐出结束符。

Prompt 就是这条「预测链」的**起点**。你输入 `法国的首都是`，模型在它学过的所有语料里，发现「巴黎」这个 token 在这句话后面出现的概率最高，于是输出「巴黎」。

所以 Prompt 的本质，是**把模型的输出分布「拉」向你想去的方向**。模型内部藏着一个巨大的概率空间（所有可能回答都有概率），Prompt 的作用不是「命令」模型，而是给这个概率空间**施加约束和偏向**：它改变条件，从而改变后续每个 token 的条件概率。这也是为什么同一个问题、换个说法，答案会差很多——因为条件变了，概率分布就变了。

这也是 Prompt 和传统编程里「命令」最根本的区别：`print("hello")` 是确定性的，机器一定会照做；但 Prompt 只是「引导」，它提高你想要结果的概率，却**不保证**结果。

### 2. 历史脉络：从「文本补全」到「指令时代」

Prompt 这个词在 AI 里其实很老，但它今天的意思，是随着模型能力一起「长」出来的：

- **早期（2018 年前后，GPT-1 / GPT-2）**：没有「Prompt 工程」这回事。模型就是个**文本续写器**，你给它开头，它顺着往下编。当时的「prompt」更像「续写开头」，人类要迁就模型，把任务伪装成一段待补全的文本。
- **GPT-3 时代（2020）**：转折点。OpenAI 的论文 *Language Models are Few-Shot Learners*（Brown et al., 2020）证明了一件大事：**只要在 Prompt 里塞几个「例子」（few-shot），模型就能学会新任务，完全不用重新训练**。这一下把「Prompt 设计」变成了正经手艺——模型没变，但你的输入质量直接决定输出质量。
- **指令微调时代（2021-2022）**：InstructGPT（OpenAI, 2022）和 FLAN（Google, 2021）这类工作，开始**专门教模型「听懂指令」**，让模型从「续写」进化成「回答问题、执行任务」。Prompt 的形态从「给例子」变成「下指令」，这才有了我们今天熟悉的用法。
- **ChatGPT 之后（2022 年末至今）**：对话式 Prompt 成为主流，同时「Prompt 工程」这个词彻底爆红，甚至催生了「Prompt Engineer（提示词工程师）」这个岗位。

一句话总结这条脉络：**模型越聪明，Prompt 从「迁就模型的续写开头」变成了「人类能直接表达意图的指令」**。

### 3. 关键概念：Prompt 的「零件」

一个高质量的 Prompt 通常由几个可拆分的部分组成（不一定要全有，但知道有这些「旋钮」很重要）：

- **指令（Instruction）**：任务本身。如「把下面这段话翻译成英文」。
- **上下文 / 背景（Context）**：给模型的外部信息，让它有据可依。如「你是一家咖啡店店长」。
- **输入数据（Input Data）**：要处理的对象。如一段待翻译的原文。
- **示例（Examples / Few-shot）**：给一两个「输入→输出」的示范，让模型照葫芦画瓢。
- **输出格式（Output Format）**：约束结果长什么样。如「只输出 JSON，不要解释」。
- **角色（Role / Persona）**：让模型扮演某个身份，如「你是一名资深 Python 工程师」。

这些零件的组合方式，就是「Prompt 工程」的核心操作空间。

### 4. 重要论文与人物

- **Brown et al., 2020 — 《Language Models are Few-Shot Learners》**：GPT-3 的论文。提出了 **in-context learning（上下文学习）**，证明「给几个例子」就能让模型做新任务，Prompt 从此成为「不用训练就能定制模型」的关键接口。这是 Prompt 研究的分水岭。
- **Wei et al., 2022 — 《Chain-of-Thought Prompting Elicits Reasoning in Large Language Models》**：提出 **思维链（CoT）**，在 Prompt 里加一句「让我们一步一步想」，就能大幅提升模型的推理能力。这篇是「用 Prompt 激发能力」的经典。
- **Kojima et al., 2022 — "Large Language Models are Zero-Shot Reasoners"**：进一步证明，甚至只要一句「Let's think step by step」，不给任何例子，也能触发推理。这让 Prompt 的「魔法感」更强了。
- **Liu et al., 2021 — 《Pre-train, Prompt, and Predict》**：系统性地把 NLP 任务统一到「Prompt」框架下，是「Prompt-based learning」这个方向的综述式代表作。
- **OpenAI — InstructGPT / ChatGPT**：把「人类指令偏好」通过 RLHF 灌进模型，让「说人话的指令」真正好用，是 Prompt 成为大众工具的直接推手。

### 5. 前沿进展：Prompt 正在「自动化」

有趣的是，Prompt 工程这个「人工手艺」，正在被 AI 自己接手：

- **自动 Prompt 优化**：用算法/模型自动搜索、改写 Prompt，找到效果最好的那版（如 APE、OPRO 等工作）。
- **System Prompt 与结构化 Prompt**：现在的主流模型（GPT-4、Claude、Gemini 等）都区分「系统提示词」和「用户提示词」，把「角色设定、长期规则」和「具体问题」分开，Prompt 变得更工程化。
- **Prompt 即编程**：随着 Agent（智能体）兴起，Prompt 不再只是一句话，而是**可以写成一整套「工作流脚本」**——包含工具调用、条件分支、自我反思。Prompt 从「问一句答一句」，走向「一套可持续运行的程序」。

所以有个反直觉的趋势值得注意：**Prompt 的最终形态，可能不是「更会写话术」，而是「把意图表达得足够清楚，剩下的交给模型和工具链」**。

## ⑤ 实际场景

- **日常对话**：你在 ChatGPT / 豆包 / 文心一言里打的那行字，就是 Prompt。
- **写作助手**：让 AI 写文案、写周报、润色文章，Prompt 的好坏直接决定成稿质量。
- **编程**：让 AI 写代码、改 bug、解释报错——「帮我重构这个函数，加上类型注解和异常处理」就是典型 Prompt。
- **图像 / 视频生成**：Midjourney、Stable Diffusion 里那一大段描述（构图、风格、光线、镜头），本质也是 Prompt，只是换成了「文生图」的入口。
- **客服 / 智能体**：企业把精心设计好的 Prompt 塞进系统，让 AI 扮演客服、销售、助教。

## ⑥ 关联术语

- **Prompt Engineering（提示词工程）**：把「写 Prompt」系统化、方法化的一套技巧与流程，是第 21 讲的主题。
- **Token（词元）**：Prompt 送进模型时，会被切成一个个 token 来计费、计量，是理解 Prompt 长度限制的前置概念。
- **Few-shot / In-context Learning（少样本 / 上下文学习）**：在 Prompt 里给示例让模型现学现卖，是 Prompt 最强大的用法之一。
